SOURCE LADDER (tested 24 Oct 2026). Use in this order; after one failure move to the next rung.
1. Groww MCP tools. Check they are in your tool list and that one call succeeds before relying on them. If they are absent or return an auth or sign-in error, skip Groww for the whole run and say so once under Data gaps. Quirks: indices need segment INDEX (under CASH, "Nifty Midcap 150" silently returns a stock); check the returned symbol every time; get_ltp takes up to 50 names; fetch_stocks_fundamental_data only with view "fundamentals" or "shareholding_only", never "all" (about 80k characters per stock). Groww's RSI is the simple 14-day (Cutler) version; mscan.py uses the same.
2. mscan.py, which needs no connector. History comes from eod2_data (NSE end-of-day, split and bonus adjusted, synced about weekly). Newer sessions come from the repo's daily NSE files: bhavcopy with delivery, index closes with P/E, and bulk and block deals, written by a GitHub Action at 18:45 IST. `day` prints STILL_MISSING sessions; fill them with --extra candles (CSV: symbol,date,open,high,low,close,volume). `show SYM ...` prints 60 sessions with delivery % for any NSE symbol or index name.
3. The web fetch tool. The shell reaches only GitHub and PyPI, so fetch pages with the web tool.
   - Today's candle: groww.in/stocks/<groww_slug> (slug in mscan output or data/universe.csv; exact NSE OHLC and volume). Else 5paisa.com/stocks/<symbol in lowercase>-share-price (check the date it shows; its volume is NSE plus BSE).
   - Fundamentals, quarters, shareholding, documents: screener.in/company/<SYMBOL>/consolidated/ (use /company/<SYMBOL>/ if consolidated is empty).
   - FII/DII cash: 5paisa.com/share-market-today/fii-dii-data. Stocks at 52-week highs: 5paisa.com/share-market-today/52-week-high (it includes micro caps; keep universe names only).
   - Filings: NSE PDFs at nsearchives.nseindia.com/corporate/... and company websites read fine. BSE PDF links (AnnPdfOpen, AttachLive, AttachHis) are blocked: web-search the same document on NSE or the company site.
   - Dead ends, don't spend time on them: Yahoo, Moneycontrol, Economic Times and Business Standard market pages, Trendlyne technical pages, NSE website APIs, Google Finance and stockanalysis.com (both serve stale prices).
